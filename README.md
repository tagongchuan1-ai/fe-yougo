# FE用語帳

基本情報技術者試験（シラバス Ver.9.2）の用語カード・4択クイズ・一覧検索アプリ（3,985語）。

- 学習記録（覚えた・苦手）は各スマホのブラウザ内にだけ保存されます。外部には送信しません。
- 一度開けば電波がなくても使えます（オフライン対応）。

## 公開手順（GitHub Pages）

1. https://github.com でアカウントを作る
2. 右上の「＋」→「New repository」
   - Repository name：`fe-yougo`（好きな名前でOK）
   - **Public** を選ぶ → 「Create repository」
3. 表示された画面の「uploading an existing file」をクリック
4. このフォルダの中身（index.html、sw.js、manifest.webmanifest、png画像4つ、README.md）をまとめてドラッグ → 「Commit changes」
5. リポジトリの「Settings」→ 左メニュー「Pages」
   - Source：「Deploy from a branch」
   - Branch：「main」「/(root)」→「Save」
6. 1〜3分待つと、Pages画面の上に公開URLが出る
   `https://（ユーザー名）.github.io/fe-yougo/`

## スマホのホーム画面に追加

- iPhone：Safariで公開URLを開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → 「︙」→「ホーム画面に追加」（または「アプリをインストール」）

## 中身を更新するとき

リポジトリで index.html を新しいファイルに置き換える（Add file → Upload files で同名ファイルを上げる）。
次にオンラインで開いたときに新しい版になります。学習記録はそのまま残ります。
